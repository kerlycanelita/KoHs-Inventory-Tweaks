# Five-version release audit: 1.0.9

Date: 2026-09-09. Reference: the user's committed Minecraft 26.1.2 tree at
`482f8cdc08a6f79f6ebb5690f20a28e5caa36812`.

## Scope and pre-change findings

Targets: 1.21.11, 26.1, 26.1.1, 26.1.2 and 26.2. No changes to 1.21.10 or
earlier targets. Preserve existing user configuration and historical releases.

The four existing Modrinth 1.0.8 binaries match their local JARs byte-for-byte
(SHA-512), but their sources are not behaviorally aligned with 26.1.2.
26.1.1 is still at 1.0.7 and also lacks the recent input and compatibility ports.

Missing ports include recipe-book visibility before screen initialization,
inventory scale-scope ownership, customization slider writes on release rather
than every movement, and the fast-open status being rendered in its own tab.

## Trust boundary and release invariants

Presentation, scale and persistence fixes are local rendering/configuration
changes (L0). Preserve the reference's one-shot cursor transaction and input
policy; do not add slot clicks, offhand actions, packet sends, cooldown changes,
held-key retries or post-open cursor correction loops.

The existing early screen-open policy is not claimed wire/timing equivalent to
Vanilla: which screen receives a later user input can change the resulting
ordinary inventory action (conservatively L2). The server still validates the
ordinary action and can observe its target and timing. There is no guarantee
of anticheat acceptance. Installed files require client cooperation to inspect.

- Inspect each target's own render lifecycle; retain the 1.21.11 render API and
  the 26.2 GUI owner API and absence of the removed snapback method.
- Build each target and check mixin selectors, handler signatures and INVOKE

- Check translation keys, packaged metadata, icons, MIT license and separation
  from the untracked debug companion.
- Run bounded offline development checks where available; report their actual
  coverage, not an assertion that every hardware/mod combination is proven.
- Publish new version numbers, preserve old files, and compare remote hashes.

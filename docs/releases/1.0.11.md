# KoHs Inventory Tweaks 1.0.11

## Supported build

- Minecraft 26.1.2.
- Fabric client-side mod.
- Fabric Loader 0.19.3 or newer.
- Fabric API 0.155.2+26.1.2.
- Java 25 or newer.

## PvP inventory response

- Removed the 25 ms press-merging heuristic. A fresh physical inventory press
  retains its own open/close meaning, even when two events arrive in one GLFW
  poll or rendered frame.
- Added `fastInventoryWhileMouseHeld`. The PvP and Performance profiles enable
  it; Vanilla and the default profile leave it off. It preserves input-conflict
  and queued-action guards, and the menu warns that earlier opening can
  interrupt a sustained world mouse action.
- Added `immediateSlotTargeting`, which refreshes the current slot before
  keyboard shortcuts, mouse-bound hotbar actions, and bundle scrolling.
- Added `suppressInventoryKeyRepeats` as an independent option. It filters only
  repeat events and does not change fresh presses, releases, or shared-binding
  fallbacks.

## Inventory Tweaks interface

- Reorganized the page into Response, Cursor, and Visuals groups.
- Added a clipped scrolling viewport with wheel and arrow navigation, stable
  switch positions, dependency-aware controls, state narration, and concise
  trade-off warnings for settings whose behavior can be useful in one scenario
  and disruptive in another.
- Updated English and Spanish translations for every new option and warning.

## Vanilla and network boundary

Closing remains Vanilla's `onClose`/`LocalPlayer.closeContainer` path. The
change does not add a close packet, replay a key, remove a tick, alter server
transactions, or change mouse sensitivity. Custom containers and creative UI
remain outside the immediate-slot refresh scope.

# KoHs Inventory Tweaks 1.0.4

## Supported builds

- Minecraft 1.21.10 — Fabric API 0.138.4+1.21.10, Java 21+
- Minecraft 1.21.11 — Fabric API 0.141.6+1.21.11, Java 21+
- Minecraft 26.1 — Fabric API 0.145.1+26.1, Java 25+
- Minecraft 26.1.1 — Fabric API 0.145.4+26.1.1, Java 25+
- Minecraft 26.1.2 — Fabric API 0.155.2+26.1.2, Java 25+
- Minecraft 26.2 — Fabric API 0.157.0+26.2, Java 25+
- Fabric Loader 0.19.3+; client-side only.

## Technical changes

- Added centered GUI scaling for single chests, double chests, Shulker Boxes, barrels, and Ender Chests. Rendering, labels, slots, carried items, hover detection, clicks, releases, and drags share the same inverse coordinate transform.
- Added a dedicated Affect Containers calibration screen. Its preview renders at vanilla 100% while disabled and immediately reflects the selected inventory scale while enabled.
- Enabled Affect all containers by default for new installations. Existing explicit user choices remain unchanged, and Reset restores the new default.
- Added Shulker Box cursor landing with independent persistence and a vanilla fallback switch.
- Expanded Issues Tracker mixin metadata scanning and added an explicit Inventory Scale Fix adaptation without treating unconfirmed conflicts as crashes.
- Added a confirmed blocking rule for Better Screens (`betterscreens`). KoHs disables its gameplay mixins and skips normal runtime registration before showing the close-only incompatibility screen because both mods transform container rendering, GUI scale state, and mouse-coordinate conversion.
- Added the maintained Minecraft 26.2 source/build target and synchronized the feature across every supported version.

## Validation

- Clean Gradle builds completed successfully for all six Minecraft targets.
- Every build produced its exact-version remapped release JAR.
- `git diff --check` completed without whitespace errors.

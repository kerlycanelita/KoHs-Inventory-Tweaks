# KoHs Inventory Tweaks 1.0.5

## Supported build

- Minecraft 26.2 — Fabric API 0.157.0+26.2, Fabric Loader 0.19.3+, Java 25+.
- Client-side only.

## Technical fix

- Fixed the Minecraft 26.2 startup crash caused by the `AbstractContainerScreenMixin` targeting the removed `extractSnapbackItem` method.
- Removed only the obsolete snapback-animation injection from the 26.2 port. Minecraft 26.2 no longer exposes `SnapbackData` or `extractSnapbackItem`, so no replacement injection is required.
- Preserved container scaling, cursor landing, item highlighting, input coordinate transforms, and every other inventory tweak.

## Validation

- Clean Gradle build completed successfully.
- The remapped JAR reports `1.0.5+mc26.2` and requires Minecraft 26.2.
- The development client completed mixin application, initialized KoHs Inventory Tweaks, and reached resource loading without the previous crash.

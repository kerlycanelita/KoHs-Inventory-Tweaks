# KoHs Inventory Tweaks 1.0.6

## Supported build

- Minecraft 26.1.2 — Fabric API 0.155.2+26.1.2, Fabric Loader 0.19.3+, Java 25+.
- Client-side only.

## Technical changes

- Removed SuperFastInventory and every related keyboard, mouse, early-screen, hovered-slot, and inherited-drag hook. Player inventory opening and all subsequent input now remain on Minecraft's vanilla client-tick path.
- Kept Center Mouse Fix as a single vanilla-centered release placement with no initialization-time re-warp, interpolation, delayed pull, or continuous pointer forcing.
- Stabilized Cursor Landing against stale queued pointer samples and bounded post-open centering events without continuously pinning the pointer.
- Added a one-shot fallback when a native hook returns the pointer to its exact pre-opening position; genuine player movement is still never pulled back.
- Removed the unused internal `slotClicked` invoker so the mod exposes no synthetic container-click path.
- Applied inventory customization to the recipe-book surface and improved customization/render cache invalidation.
- Removed all Herzium-specific compatibility handling. KoHs no longer inspects, reports, pauses features for, or otherwise manipulates Herzium.
- Changed Raw Input Buffer and Ixeris, individually or together, to pause only custom Cursor Landing; the combination no longer blocks startup or disables Center Mouse Fix or any other Inventory Tweaks control.
- Made Raw Input Buffer handling truthful and deterministic: its confirmed mouse-position overlap disables only Cursor Landing; no unreachable reflective adapter or foreign-target compatibility mixin remains.
- Packaged the MIT license in the release JAR and synchronized the English and Spanish behavior documentation.

## Trust boundary

- The mod sends no custom inventory packets and performs no deferred or duplicate swap.
- The inventory key, screen creation, offhand action, hotbar action, clicks, and packet timing remain on Minecraft's unmodified input path. Center Mouse Fix changes only local pointer coordinates and sends no packet.

## Validation

- Translation verification passed: all 159 referenced keys resolve in English and every Spanish locale generated by the build.
- Minecraft 26.1.2 mixin verification passed: 59 member references and 9 invocation points resolve against the target client JAR.
- Clean Gradle build completed successfully with no Gradle or remap warnings.
- The remapped JAR reports `1.0.6+mc26.1.2`, requires exactly Minecraft 26.1.2 and Java 25+, contains the MIT license and all eight language files, and has no duplicate archive entries.
